# Changelog

## 1.2.3
- Оборванный ответ stopice (`IncompleteRead`) больше не считается ошибкой, если JSON пришёл целиком.
- При таймауте, обрыве или rate limit stopice запрос по точке повторяется один раз через 5 секунд.

## 1.2.2
- Ошибка отправки сообщения о запуске больше не роняет add-on, а пишется в журнал.

## 1.2.1
- Опции `antifreeze_enabled` и `notify_on_start` стали необязательными: настройки от прошлых версий сохраняются без ошибки.

## 1.2.0
- Добавлен источник antifreeze.app (включая репорты iceout.org).
- Копии репортов stopice.net из antifreeze пропускаются.
- Поддержка Moderator Notes, если они появятся в API stopice.

## 1.1.0
- Произвольный список точек `locations` со своим радиусом.

## 1.0.0
- Первая версия: репорты stopice.net в Telegram.
