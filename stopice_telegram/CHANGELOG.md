# Changelog

## 1.12.5
- Тревога «1 миля»: на iPhone — критическое уведомление; на Android — обычное уведомление (как для остальных уровней) плюс короткий голосовой сигнал «1 mile» через громкость будильника. Текст сигнала по-прежнему меняется опцией `alarm_tts_text`.

## 1.12.4
- Голосовая тревога «1 миля» уходит только на Android; на iPhone больше не приходит лишнее уведомление «TTS». Тип телефона определяется автоматически, при необходимости его можно указать вручную: `platform: ios` или `platform: android` в записи `geo_alerts`.
- Опция `alarm_tts_text` — свой текст голосовой тревоги (например, по-английски, если русский голос звучит с акцентом).

## 1.12.3
- iPhone: тревога «1 миля» приходит как критическое уведомление со звуком на полной громкости — звучит и в беззвучном режиме, если в приложении Home Assistant разрешены критические уведомления.

## 1.12.2
- Тревога «1 миля» дополнительно проговаривается голосом через громкость будильника на максимуме — так её слышно и в беззвучном режиме (будильники должны быть разрешены в «Не беспокоить»).

## 1.12.1
- Уведомления можно слать на несколько телефонов одного человека: укажите его в `geo_alerts` несколько раз с разными `notify`.

## 1.12.0
- Пуш-уведомления по геопозиции через приложение Home Assistant: если рядом с человеком появился сегодняшний репорт, на его телефон приходит тревога по уровням — 1, 3, 10 и 15 миль — с расстоянием, адресом и «Опубликовано N минут назад». Если человек подъехал ближе и уровень вырос, приходит новое уведомление. Тревога «1 миля» на Android звучит как будильник даже в беззвучном режиме.
- Настройка — опция `geo_alerts`: список пар `person` (например, `person.otets`) и `notify` (например, `mobile_app_pixel_otsa`).

## 1.11.1
- На карте в боковой панели Home Assistant видны ваши места — зоны Home Assistant (дом 🏠, офис и другие 📍) с подписью и пунктирным кругом радиуса. Новые места добавляются в «Настройки → Области и зоны → Зоны». На публичной карте их нет.

## 1.11.0
- Новая панель для бокового меню Home Assistant: та же карта, что публичная (зоны и репорты за сегодня, без прошлых инцидентов), плюс члены семьи из Home Assistant. Члены семьи видны только внутри HA. Адрес панели — в журнале add-on'а; добавляется один раз через «Настройки → Панели → Добавить панель → Веб-страница». Нужна включённая `public_page`.
- Метки и зоны на карточке «Карта» убраны: add-on удаляет их сам при запуске. Опция `ha_map` больше ничего не делает.

## 1.10.1
- Метки репортов на карте Home Assistant — цветные кружки с числом (цвета как на публичной карте) вместо нечитаемых букв; название вида «118 Sunrise Ave — Не подтверждено», время публикации в атрибуте `published`.

## 1.10.0
- Репорты за сегодня и зоны теперь видны на карточке «Карта» в панелях Home Assistant. Репорты — объекты `geo_location` с источником `ice_monitor`, зоны — пассивные `zone.ice_monitor_N` с радиусом (на «дома/не дома» людей не влияют). Готовый YAML карточки — в журнале add-on'а при запуске. Выключается опцией `ha_map: false`.

## 1.9.1
- Репорты о прошлых инцидентах («ПРОШЛЫЙ ИНЦИДЕНТ», «Prior incident reporting for record») больше не попадают на карту сегодняшних репортов. В Telegram они по-прежнему приходят.
- Ссылки под репортом: «Репорт · Локация · Общая карта» — последняя ведёт на публичную карту (если она включена и задан `public_base_url` или внешний адрес Home Assistant).

## 1.9.0
- На публичной карте видно своё местоположение: зелёная точка с кругом точности. Кнопка «◎» под кнопками масштаба переносит карту к вам. Координаты остаются в браузере и никуда не отправляются. Работает по HTTPS (например, через Home Assistant Cloud) после разрешения доступа к геопозиции.

## 1.8.6
- На картах один и тот же случай из нескольких источников показывается одной точкой с числом репортов; по нажатию видны все.
- Сегодняшние репорты на карте больше не пропадают при перезапуске или обновлении add-on'а.

## 1.8.5
- Репорты на картах (и в боковой панели, и на публичной) лежат поверх зон, открываются по нажатию и стали вдвое крупнее.
- Публичная карта больше не застревает в кэше браузера: обновления add-on'а (например, репорты из Telegram в легенде) видны сразу. После этого обновления один раз обновите страницу с очисткой кэша (Ctrl+F5).

## 1.8.4
- Срочный репорт (URGENT) приходит, даже если о том же месте уже был обычный или неподтверждённый репорт — он больше не считается дублем.

## 1.8.3
- В репорте больше нет строки с названием зоны и расстоянием — адреса достаточно.
- Посты из Telegram-канала без дублей: русская копия поста, «Комментарий: Нет» и пустые комментарии не попадают в сообщение.
- «Confirmed by a community partner» показывается одной строкой с названием организации, например «📢 CONFIRMED BY NorCal Resist»; если описание только это и повторяет, оно не дублируется.
- На публичной карте зоны больше не перехватывают нажатия — репорты внутри зон снова открываются.

## 1.8.2
- Фото из Telegram-каналов теперь приходят вместе с репортом: если Telegram не может забрать картинку по ссылке, add-on скачивает и загружает её сам.

## 1.8.1
- Опция `telegram_topic_id`: все сообщения бота (репорты, сообщение о запуске, ссылка на карту, release notes) уходят в указанный топик группы.

## 1.8.0
- Новый источник — публичные Telegram-каналы с репортами, по умолчанию t.me/icetracking. Читаются через открытую веб-версию канала, аккаунт Telegram не нужен. Список каналов — опция `telegram_channels`.
- Один и тот же репорт из разных источников (рядом по месту и в пределах 3 часов) больше не приходит дважды.
- На картах репорты из Telegram-каналов отмечены голубым.

## 1.7.0
- Add-on переименован в ICE Monitor: источников репортов теперь несколько, не только stopice.net. Пункт в боковой панели тоже называется ICE Monitor.
- Настройки, точки и ссылка на публичную карту сохраняются.

## 1.6.1
- При каждом запуске бот присылает в Telegram ссылку на публичную карту (если включена `public_page`).
- Новая опция `public_base_url` — адрес Home Assistant для ссылки, например адрес Nabu Casa. Если не задана, берётся внешний адрес из настроек сети Home Assistant.

## 1.6.0
- Публичная карта через Home Assistant Cloud: опция `public_page` выкладывает страницу просмотра (зоны и репорты за сегодня) в папку `www` Home Assistant. Адрес со случайным именем папки появляется в журнале add-on'а и открывается без входа.

## 1.5.0
- Карта по прямому порту стала только для просмотра: зоны и репорты за сегодня (с полуночи до полуночи по тихоокеанскому времени), без панели и без возможности менять точки.
- Создавать и редактировать точки теперь можно только через боковую панель Home Assistant.
- В карточке репорта на карте видны описание и ссылка на репорт.

## 1.4.0
- Карту можно открыть по сети без входа в Home Assistant: задайте порт в разделе «Сеть» настроек add-on'а (по умолчанию выключено).
- Необязательная опция `web_password` — пароль для такого прямого доступа (логин любой). Через боковую панель Home Assistant пароль не спрашивается.

## 1.3.1
- Карта не загружалась внутри Home Assistant (OpenStreetMap блокировал тайлы) — теперь тайлы загружает сам add-on. В тёмной теме карта тоже тёмная.
- Поиск адреса на карте идёт через сам add-on.

## 1.3.0
- Карта точек: в боковой панели Home Assistant появился раздел StopICE — точки ставятся кликом по карте, радиус задаётся ползунком и сразу виден кругом.
- Изменения точек с карты применяются без перезапуска add-on'а.
- На карте видны последние репорты в ваших зонах.
- После каждого обновления бот присылает в Telegram список изменений.

## 1.2.3

- При таймауте, обрыве или rate limit stopice запрос по точке повторяется один раз через 5 секунд.

## 1.2.2
- Ошибка отправки сообщения о запуске больше не роняет add-on, а пишется в журнал.

## 1.2.1

- Поддержка Moderator Notes, если они появятся в API stopice.
